# ⭐ StudyZone – An EdTech Platform

StudyZone is a full-stack EdTech platform built with the MERN stack. It helps students and instructors learn, teach, and share resources in a simple and organized way. The platform supports secure authentication, smooth course management, and an interface that’s easy to use for everyone.

---

## 🚀 Features

### 🔐 Secure Authentication
- JWT-based login and signup  
- Protects user data and ensures safe access  

### 📘 Course Management (Full CRUD)
- Instructors can create, update, and delete courses  
- Students can browse and enroll in courses  
- Clean and simple UI to follow lessons

### 🧑‍🏫 Student–Teacher Interaction
- Tools to share resources, notes, and updates  
- Helps both sides communicate easily  

### ☁ Media Uploads
- Cloudinary integration for images and files  

### ⚡ Fast & Scalable
- MERN stack for performance and growth  
- Tailwind CSS for responsive design  

---

## 🛠️ Tech Stack

**Frontend**
- React.js  
- Tailwind CSS  
- React Hook Form  
- React Toast  

**Backend**
- Node.js  
- Express.js  
- MongoDB + Mongoose  
- JWT Authentication  
- Cloudinary
